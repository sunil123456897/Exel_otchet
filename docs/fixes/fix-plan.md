## P2 — Значимые исправления

### FIX-006: Детали ошибки в toast
- **UX**: UX-003
- **Фича**: F-026
- **Файл**: `APP/core/ui/widgets/toast.py`
- **Проблема**: Error toast не показывает причину ошибки

- **Оценка**: 45 минут

### FIX-007: Информативный cancel toast
- **UX**: UX-005
- **Фича**: F-021
- **Файл**: `APP/core/ui/main_window.py`
- **Проблема**: Cancel toast не показывает, сколько обработано и есть ли .partial
- **Решение**: Формат сообщения: «Отменено на {percent}%. Обработано {done}/{total}. {partial_info}»
- **Тест**: US-021-S3 (расширить — проверить формат сообщения)
- **Риск**: Низкий — изменение строки сообщения
- **Оценка**: 20 минут

### FIX-008: Удаление config_missing.yaml
- **TD**: TD-013
- **Файл**: `APP/config_missing.yaml`
- **Проблема**: Редундантный файл, дубликат config.example.yaml
- **Решение**: Удалить файл
- **Тест**: Проверить, что нет ссылок на config_missing.yaml
- **Риск**: Очень низкий
- **Оценка**: 5 минут

### FIX-009: Текущий файл в progress bar
- **UX**: UX-007
- **Фича**: F-024
- **Файл**: `APP/core/ui/main_window.py` + `APP/core/ui/widgets/operation_status_bar.py`
- **Проблема**: Progress не показывает, какой файл обрабатывается
- **Решение**: on_progress принимает optional current_file, status bar показывает «Обработка: {file} ({i}/{n})»
- **Тест**: US-024-S1 (расширить — проверить current_file в status)
- **Риск**: Средний — изменение callback signature
- **Оценка**: 40 минут

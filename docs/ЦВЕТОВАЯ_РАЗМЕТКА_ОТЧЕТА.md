# Цветовая Разметка Отчета

Короткая памятка по цветам в `Master_Report.xlsx`.

## Желтая строка
- Значит, по строке есть подозрение на математическую ошибку.
- Обычно это один из случаев:
- `ИТОГ = 0` или пустой, хотя есть `Приход` или `Расход`.
- `Комиссия = 0`, но `ИТОГ` не равен `Приход - Расход`.

## Красный `Источник`
- Значит, проблема связана со структурой шаблона строки или файла.
- Это используют для structural warning, например:
- `hard_structure`
- другие предупреждения, где нельзя привязать ошибку к одной конкретной колонке.

## Красная конкретная колонка
- Значит, в исходнике текст попал в числовое поле.
- Для ошибок вида `text in numeric field: <поле>` красится именно проблемная колонка.
- Примеры:
- `text in numeric field: total` -> красный `ИТОГ`
- `text in numeric field: commission` -> красная `Комиссия`
- `text in numeric field: expense` -> красный `Расход`

## Красный `% посредника`
- Значит, процент посредника некорректный.
- Например, там текст вместо числа или значение выглядит как невозможный процент.

## Зеленый `Приход`
- Это нормальная визуальная подсветка входящих денег.
- Не ошибка.

## Красный/розовый `Расход`
- Это нормальная визуальная подсветка расхода.
- Не ошибка.

## Серая и белая зебра
- Это просто фон для удобства чтения.
- Не ошибка.

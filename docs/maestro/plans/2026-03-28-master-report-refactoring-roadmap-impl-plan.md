# План реализации рефакторинга

## 1. Обзор плана
Этот план описывает поэтапный рефакторинг системы «Master Report» в «Гибридный кэш» (SQL + Excel). Основная цель — повысить скорость, надежность и чистоту кода, сохраняя Excel как интерфейс.

## 2. Граф зависимостей
```
Phase 1 (Foundation)
    |
Phase 2 (Data Layer)
    |
Phase 3 (Core Logic)
    |
Phase 4 (Integration)
    |
Phase 5 (Quality Gate)
    |
Phase 6 (Documentation)
```

## 4. Детали фаз

### Фаза 1: Foundation (Architect)
- **Цель**: Определить архитектурные границы и схему данных.
- **Файлы для создания**: `APP/src/db_schema.sql`, `APP/src/interfaces.py`.
- **Файлы для изменения**: `APP/config.yaml`.
- **Валидация**: Проверка синтаксиса SQL, проверка соответствия интерфейсов дизайну.

### Фаза 2: Data Layer (Data Engineer + Coder)
- **Цель**: Реализовать слой сохранения данных и импорт из Excel.
- **Файлы для создания**: `APP/src/sqlite_manager.py`, `APP/src/ingestion.py`.
- **Файлы для изменения**: `APP/audit_logic.py`.
- **Валидация**: Тест на вставку 1000+ строк, проверка механизма блокировок `.lock`.

### Фаза 3: Core Logic (Coder)
- **Цель**: Перенести правила расчета в новый формат.
- **Файлы для создания**: `APP/src/logic_service.py`.
- **Файлы для изменения**: `APP/src/consolidator.py` (частичный рефакторинг).
- **Валидация**: Сравнение результатов расчетов (SQL vs Старая версия).

### Фаза 4: Integration (Coder)
- **Цель**: Соединить все части в единое приложение.
- **Файлы для изменения**: `APP/main.py`, `APP/src/gui_master.py`, `APP/src/writer.py`.
- **Валидация**: Полный прогон от выбора папки до генерации мастер-файла.

### Фаза 5: Quality Gate (Tester)
- **Цель**: Обеспечить 100% надежность.
- **Файлы для создания**: `APP/tests/test_sql_logic.py`, `APP/tests/test_locking.py`.
- **Валидация**: Успешное выполнение `pytest`.

### Фаза 6: Documentation (Technical Writer)
- **Цель**: Актуализировать знания о системе.
- **Файлы для изменения**: `README.md`, `APP/docs/README_TECHNICAL.md`.
- **Валидация**: Проверка ссылок и инструкций по установке.

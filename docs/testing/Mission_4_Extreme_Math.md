# Миссия 4: "Математик-экстремал" (LogicService & MasterWriter)

**Цель:** Проверить корректность финансовых вычислений, обработку граничных значений и работу визуальных индикаторов в итоговом отчете.

## 🛑 Правило Hard Stop
**Тест считается проваленным, если:**
1. Произошел Python traceback.
2. Итоговая сумма (ИТОГО) в Excel не совпадает с суммой ячеек выше.
3. Математическая ошибка в строке не подсвечена желтым.
4. Нарушение шаблона (например, пустая дата) не подсвечено красным в колонке "Источник".

---

## Чек-лист проверок

### 1. Граничные комиссии (0% и 100%)
*   **Действие:** 
    *   Строка 1: Сумма 1000, комиссия 0%.
    *   Строка 2: Сумма 1000, комиссия 1000 (или 100%).
*   **Ожидаемый результат:** 
    *   При 0% комиссии: Приход 1000, Расход 0, Итог 1000.
    *   При 100% комиссии: Приход 1000, Расход 1000, Итог 0.
*   **Проверка:** [ ] Строка с 0% комиссии рассчитана верно.
*   **Проверка:** [ ] Строка с 100% комиссии рассчитана верно (Итог = 0).

### 2. Отрицательный баланс (Возвраты)
*   **Действие:** Создайте отчет, где сумма возвратов превышает сумму приходов. Например: Приход 5000, Возврат 7000.
*   **Ожидаемый результат:** 
    *   Программа должна корректно записать 5000 в "ПРИХОД" и 7000 в "РАСХОД".
    *   Итог по строке возврата может быть отрицательным или нулевым (в зависимости от логики комиссии), но общий ИТОГО по колонке в Excel должен быть корректным (например, -2000).
*   **Проверка:** [ ] Возвраты попали в колонку "РАСХОД".
*   **Проверка:** [ ] Финальная формула `SUM` в Excel выдает математически верный результат.

### 3. Пустые отчеты и "Дыры"
*   **Действие:** 
    *   Файл, в котором есть только шапка и ни одной строки данных.
    *   Файл, где в одной из строк пропущена дата или имя заказчика.
*   **Ожидаемый результат:** 
    *   Пустой файл не должен вызывать падения (просто пропускается или создается пустая секция).
    *   Строка с пропущенными обязательными полями должна быть помечена красным в колонке "Источник" (Template Warning).
*   **Проверка:** [ ] Программа не упала на пустом файле.
*   **Проверка:** [ ] Строка без даты подсвечена красным (ячейка в колонке "Источник").

### 4. Экстремальные числа (Billions)
*   **Действие:** Введите сумму `9 999 999 999.99` (почти 10 миллиардов).
*   **Ожидаемый результат:** 
    *   Тип `Decimal` должен сохранить точность до копеек.
    *   Excel должен отобразить число корректно (проверьте, не превратилось ли оно в `1E+10`).
*   **Проверка:** [ ] Число-миллиардник сохранило точность `.99`.
*   **Проверка:** [ ] В Excel ячейка имеет числовой формат и корректное значение.

### 5. Визуальные триггеры (Highlighting)
*   **Действие:** Намеренно внесите в исходный файл данные, которые приведут к "математической странности" (например, Сумма 1000, Комиссия 0, но Итог 500 — если программа позволяет такое вводом или если это логическая ошибка). *Примечание: В текущей версии 5.5 "математическая ошибка" срабатывает, если комиссия 0, но сумма и итог не равны.*
*   **Ожидаемый результат:** 
    *   Ячейки в такой строке должны окраситься в желтый цвет.
*   **Проверка:** [ ] Желтая подсветка сработала на расхождении суммы и итога при нулевой комиссии.
*   **Проверка:** [ ] Красная подсветка в колонке "Источник" сработала при нарушении структуры (is_warning).

# Миссия 3: "Злой бухгалтер" (Stress-Test IngestionEngine)

**Цель:** Проверить устойчивость движка парсинга Excel к намеренным ошибкам в структуре и данных исходных файлов.

## 🛑 Правило Hard Stop
**Тест считается проваленным, если:**
1. Произошел Python traceback (окно ошибки с техническим текстом).
2. Программа "молча" пропустила критическую ошибку (например, не заметила отсутствие колонки и выдала пустой результат без предупреждения в логах).
3. Данные были смещены (значения попали не в те колонки в базе данных/итоговом отчете).

---

## Чек-лист проверок

### 1. Двойные шапки (Double Headers)
*   **Действие:** Создайте файл, где первая строка — мусор или старая шапка, а реальная шапка (с названиями колонок) находится на 5-й строке. Между ними — пустые строки или случайный текст.
*   **Ожидаемый результат:** `IngestionEngine` должен найти валидную шапку по маркерам (например, "Заказчик", "Сумма платежа") и начать парсинг с корректной строки.
*   **Проверка:** [ ] Данные из строк ниже 5-й корректно попали в отчет.

### 2. Скрытые и "неправильные" листы
*   **Действие:** 
    *   Добавьте в файл скрытый лист (Hidden Sheet) с валидными данными.
    *   Создайте листы с именами: `32.01.2024` (несуществующая дата), `февраль_2024` (текст вместо даты), `20.03.26` (корректный формат).
*   **Ожидаемый результат:** 
    *   Скрытые листы должны игнорироваться или обрабатываться корректно (в зависимости от настроек, но не вызывать падение).
    *   Листы с некорректными датами не должны приводить к падению; в логах должно быть предупреждение о невозможности распознать дату.
*   **Проверка:** [ ] Лист `20.03.26` обработан. 
*   **Проверка:** [ ] Ошибки на листах `32.01.2024` и `февраль_2024` не остановили процесс.

### 3. Война колонок (Missing & Swapped Aliases)
*   **Действие:** 
    *   Удалите одну обязательную колонку (например, "Сумма платежа").
    *   Поменяйте местами колонки "Заказчик" и "Исполнитель".
    *   Переименуйте "Сумма платежа" в "Бабки" (неизвестный алиас).
*   **Ожидаемый результат:** 
    *   При отсутствии обязательной колонки программа должна выдать ошибку в лог для этого файла.
    *   При смене мест колонок данные должны определиться по именам шапки, а не по индексам.
*   **Проверка:** [ ] Поменянные местами колонки определены верно.
*   **Проверка:** [ ] Файл с "Бабками" вместо суммы не вызвал падения, в логах зафиксирована ошибка структуры.

### 4. Разделители и "грязный" текст
*   **Действие:** 
    *   В колонке суммы напишите `1500,50` (запятая) и `2 000.00` (пробел-разделитель тысяч).
    *   В шапке сделайте лишние пробелы: `"  Заказчик  "`, `"Сумма   платежа"`.
*   **Ожидаемый результат:** 
    *   Суммы должны быть преобразованы в `Decimal(1500.50)` и `Decimal(2000.00)`.
    *   Лишние пробелы в шапке должны обрезаться (strip) при сопоставлении с маркерами.
*   **Проверка:** [ ] Числа с запятыми распознаны.
*   **Проверка:** [ ] Шапка с пробелами распознана.

### 5. Смешанные расширения
*   **Действие:** Положите в папку сотрудника два файла с одинаковыми данными: один `.xlsx`, другой `.xlsb`.
*   **Ожидаемый результат:** Оба расширения поддерживаются. Программа должна обработать оба файла или (если настроено исключение дублей по хешу) пропустить один, но не упасть.
*   **Проверка:** [ ] Файлы `.xlsx` и `.xlsb` успешно прочитаны.

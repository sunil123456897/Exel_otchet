# Edge Cases — Матрица граничных условий

## Метаданные
- Дата: 2026-06-26
- Проект: Master-Report v5.5
- Источник: docs/specs/user-stories.md + docs/business/invariants.md + docs/risks/tech-debt.md
- Всего edge-кейсов: 168 (4 на каждую из 42 фич)
- Формат: матрица boundary conditions × feature

---

## Категории граничных условий

| Категория | Описание |
|-----------|----------|
| **B1: Boundary values** | Минимальные/максимальные значения, off-by-one, пустые коллекции |
| **B2: Concurrency** | Состояния гонки, отмена во время операции, double-click, deadlock |
| **B3: I/O & External** | Сеть, диск, файлы заняты, permission denied, encoding |
| **B4: Data integrity** | Повреждённые данные, невалидные форматы, missing fields, injection |

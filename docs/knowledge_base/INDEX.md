# 📚 База знаний проекта Master-Report v5.5 "Elite"

Добро пожаловать в структурированную документацию проекта. Master-Report — это высокопроизводительная система консолидации финансовых отчетов из множества Excel-источников, оптимизированная для работы в нестабильных сетевых средах (SMB).

## 🗺 Карта контента (MOC)

### 🏗 Архитектура и Структура
- [[ARCHITECTURE]] — Описание слоев (Domain, Infra, UI) и принципов разделения ответственности.
- [[TECHNOLOGY_STACK]] — Ключевые библиотеки и инструменты (Calamine, Pydantic, SQLite WAL).

### ⚙️ Технические процессы
- [[INGESTION_PIPELINE]] — Алгоритм парсинга Excel, двухпроходное определение заголовков и очистка данных.
- [[NETWORK_OPTIMIZATION]] — Стратегия "Local Copy" для ускорения работы с сетевыми дисками SMB.
- [[FINANCIAL_LOGIC]] — Правила обработки комиссий, разделение потоков и округление.

### 🧪 Качество и Тестирование
- [[TESTING_INFRASTRUCTURE]] — Описание Toxic Data, Black Swan сценариев и стресс-тестирования.
- [[DB_RESILIENCE]] — Устойчивость базы данных к конкурентным нагрузкам.

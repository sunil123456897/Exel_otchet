# ⚙️ Технологический стек

Для обеспечения экстремальной производительности и надежности в версии 5.5 "Elite" выбраны следующие инструменты:

## 🦀 python-calamine
Замена стандартным `openpyxl` и `pandas` для чтения файлов.
- **Почему**: Написан на Rust, работает в 10-50 раз быстрее.
- **Особенности**: Позволяет читать `.xlsb` (двоичный формат Excel), который часто используется в крупных корпоративных отчетах.

## 🛡 Pydantic (v2)
Слой валидации данных.
- **Почему**: Гарантирует целостность типов. При попытке загрузить строку вместо суммы система не упадет, а корректно обработает ошибку на уровне модели.
- **Политика**: Используется `coerce_numbers_to_str=True` и `extra='allow'` для гибкости при сохранении строгой типизации полей.

## 🗄 SQLite (WAL Mode)
Локальное хранилище данных.
- **Режим WAL (Write-Ahead Logging)**: Позволяет одновременно писать и читать из базы без блокировок. Это критично при многопоточном сканировании сетевых папок.
- **Декораторы Retry**: Используются для обработки редких случаев `database is locked`.

## 🎨 Tkinter + Custom Theme
Легкий и быстрый GUI.
- Приложение использует нативную библиотеку для максимальной отзывчивости на слабых ПК кураторов.

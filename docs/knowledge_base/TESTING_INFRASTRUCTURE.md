# 🧪 Инфраструктура тестирования

Проект Master-Report v5.5 имеет одну из самых мощных систем тестирования среди аналогичных утилит.

## 1. Toxic Data (Токсичные данные)
Комплект из 11 файлов (`tests/fixtures/toxic_data`), содержащих:
- Опечатки в датах (31.04).
- Пустые финансовые колонки.
- Математические ошибки (сумма + комиссия != итог).
- Лишние мусорные строки в середине таблицы.

## 2. Black Swan Scenarios (Черный лебедь)
Экстремальные случаи в `tests/test_black_swan.py`:
- **Unicode Invisible**: Невидимые символы в названиях листов.
- **Excel Desert**: Данные начинаются на 5000-й строке.
- **Fake XLSX**: Текстовые файлы, замаскированные под Excel.
- **Precision Hell**: Числа с 20+ знаками после запятой.

## 3. Stress & Chaos (Стресс и Хаос)
- **Multi-threading**: Проверка 8+ одновременных потоков записи в SQLite.
- **Network Ghosting**: Имитация исчезновения файла прямо во время его чтения.

### Как запустить тесты
```powershell
pytest -v -s --log-cli-level=INFO
```

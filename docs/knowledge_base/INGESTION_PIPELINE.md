# 🚜 Конвейер парсинга (Ingestion Pipeline)

Парсинг — самый сложный этап из-за "творческого" подхода кураторов к ведению таблиц.

## CalamineReader
Реализован в `ingestion_readers.py`. Использует две фазы обработки листа:

### Фаза 1: Определение заголовков (Two-Pass Detection)
1. Система сканирует первые **6000 строк** листа (увеличено для поддержки "пустых" отчетов).
2. Для каждой строки рассчитывается **Score** на основе списка алиасов (синонимов).
3. Если Score >= 3 и найдены обязательные поля (`amount` + `customer`), строка фиксируется как заголовок.
4. **Ранний выход**: Если Score >= 5, сканирование прекращается для экономии времени.

### Фаза 2: Извлечение данных
- Используется `active_col_map`, сформированная в Фазе 1.
- Каждая строка проверяется на "мусор" (ключевые слова типа 'итого', 'всего', 'название клиента').
- Проводится очистка **Unicode-невидимок** (Zero-Width Space `\u200B` и др.).

## Обработка дат
Функция `extract_date_from_sheet` извлекает дату из названия листа (`01.04.2026`).
- **Resilience**: Если дата некорректна (напр. 31.04), она логируется как `DEBUG` и строка получает метку `01.01.1900` (Temporal Fallback) вместо того, чтобы потеряться.

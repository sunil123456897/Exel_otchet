# 🚀 Сетевая оптимизация

Работа с файлами через SMB (сетевые диски Q:, Z: или UNC-пути) часто сопровождается задержками и случайными обрывами связи.

## Стратегия "Local Copy"
Вместо того чтобы заставлять Rust-парсер (`python-calamine`) постоянно обращаться к сети в поисках фрагментов ZIP-архива Excel, система делает следующее:

1. **Детекция**: `DiscoveryService` проверяет, является ли путь сетевым.
2. **Копирование**: Файл копируется во временную папку пользователя (`tempfile.mkstemp`) через `shutil.copy2`. Это происходит один раз на файл.
3. **Локальный парсинг**: Calamine читает файл с локального SSD/HDD с максимальной скоростью.
4. **Очистка**: После чтения временная копия немедленно удаляется (блок `finally`).

### Результаты оптимизации
- **Скорость**: Увеличение в 5-10 раз на нестабильных каналах.
- **Надежность**: Если сеть пропадет *после* копирования, парсинг завершится успешно. Если *во время* копирования — система корректно пропустит файл без падения (тест `test_ghost_file_deletion_mid_read`).

## 1. Знакомство с программой

**Master-Report Consolidator v5.6** — это Windows-программа для финансовой консолидации. Она собирает Excel-отчёты сотрудников из сетевых папок в один сводный **Master-отчёт**, формирует **РСЧ** (расчётно-кассовый отчёт по банковским счетам) и делает **сверку** — отчёт расхождений между Master-отчётом и РСЧ.

Программа рассчитана на работу с 23 сотрудниками, чьи файлы лежат на сетевых дисках (например, `Q:\Отчет кураторов …`). Все действия выполняются мышкой и клавиатурой — ничего программировать не нужно.

> **Коротко о трёх главных действиях:**
> - 📊 **Сборка** — собирает Master-отчёт за день, период или все даты сразу (куратор: Общий / Борис / Иван).
> - 🧾 **РСЧ** — формирует расчётно-кассовый отчёт по банковским счетам.
> - ✅ **Сверка** — сравнивает Master с РСЧ и показывает расхождения; есть **авто-сверка**, которая за один клик делает 3 Master + РСЧ + сверку.

## 2. Первый запуск

### Что нужно заранее

На компьютере должен быть установлен **Python 3.12 или новее**. Скачать: [python.org](https://www.python.org/downloads/). При установке обязательно поставьте галочку **«Add Python to PATH»**.

> Больше ничего ставить не нужно — `ЗАПУСК.bat` сам создаст изолированное окружение и доустановит библиотеки.

### Как запустить

1. Откройте папку с программой (например, `E:\Dlia Dashi\Version5`).
2. Дважды кликните по файлу **`ЗАПУСК.bat`**.
3. Появится чёрное окно с надписью `MASTER REPORT CONSOLIDATOR v5.5` и шагами `Step 1/5 … Step 5/5`.
4. Дождитесь надписи **«DONE. The application is starting...»** — окно закроется само через 3 секунды.
5. Откроется главное окно программы.

**Ожидаемый результат:** на экране — главное окно Master-Report с левой панелью управления и вкладками справа.

### Welcome-диалог (показывается один раз)

При самом первом запуске поверх главного окна появится приветственное окно **«👋 Добро пожаловать в Master-Report»** с тремя шагами:

```
1. Добавьте сотрудников (кнопка ➕ Добавить в левой панели)
2. Выберите дату для консолидации
3. Нажмите Сборка → Собрать день (или Ctrl+D)
```

Нажмите **«Начать работу»** (или Enter / Esc) — диалог закроется и больше не появится. Флаг первого запуска сохраняется в файле `APP/first_run.json`.

**Ожидаемый результат:** диалог исчезает, открывается доступ к главному окну.

### Если программа не запускается

См. раздел [FAQ → «Программа не запускается»](#вопрос-1-программа-не-запускается). Кратко: проверьте `startup_log.txt` и `gui_error_log.txt` рядом с `ЗАПУСК.bat` — там написана причина.

## 4. Сценарий 1: собрать отчёт за день

Самая частая задача — собрать Master-отчёт по файлам сотрудников за одну конкретную дату.

1. **Убедитесь, что сеть доступна.**
   Вверху левой панели индикатор должен быть зелёным: **«🟢 Сеть: 3/3 дисков доступны»**.
   Если красный — файлы сотрудников недоступны, сборка не получится. См. [FAQ → «Сеть недоступна (🔴)»](#вопрос-5-сеть-недоступна--).

   **Ожидаемый результат:** индикатор зелёный.

2. **Выберите дату в блоке «📅 ВЫБОР ДАТЫ».**
   Кликните по календарю и выберите нужный день (например, 09.07.2026). Даты листов в файлах сотрудников имеют формат `DD.MM.YYYY`.

   **Ожидаемый результат:** в поле календаря отображается выбранная дата.

3. **Выберите куратора в блоке «🚀 СБОРКА».**
   В выпадающем списке «Кураторский отчет:» выберите один из трёх вариантов:
   - **Общий отчет** — сводный отчёт по всем сотрудникам;
   - **Куратор Борис** — отчёт по сотрудникам куратора Бориса;
   - **Куратор Иван** — отчёт по сотрудникам куратора Ивана.

   **Ожидаемый результат:** в поле списка отображается выбранный куратор.

4. **Нажмите кнопку «⚡ СОБРАТЬ ДЕНЬ».**
   Эквивалент — сочетание клавиш **Ctrl+D**. Внизу панели (StatsPanel) появится прогресс-бар. Программа читает файлы сотрудников, находит лист с выбранной датой и собирает строки.

   **Ожидаемый результат:** прогресс-бар растёт, вверху вкладки «Сотрудники» статусы обновляются (зелёные бейджи у готовых файлов).

5. **Дождитесь завершения.**
   По окончании появится всплывающее уведомление (тост) с результатом. Появится предложение выбрать, куда сохранить итоговый файл, и кнопка открыть файл или папку.

   **Ожидаемый результат:** тост «успех» (зелёный), файл `Master_Report.xlsx` (или отчёт куратора) создан/обновлён.

6. **Откройте результат.**
   Во вкладке «Отчеты» появится строка с новым файлом. Кликните по ней, чтобы открыть файл или папку с ним.

   **Ожидаемый результат:** Excel-файл открывается, на листе «СВОД» — собранные строки.

> **Подсказка:** чтобы не делать 3 отдельных сборки и сверку вручную, используйте [авто-сверку](#6-сценарий-3-авто-сверка).

## 5. Сценарий 2: собрать за период

Когда нужен отчёт не за один день, а за диапазон дат (например, за весь месяц).

1. **Разверните секцию «📆 ЗА ПЕРИОД».**
   В левой панели найдите блок «📆 ЗА ПЕРИОД» и нажмите кнопку **«▶  Развернуть»**.

   **Ожидаемый результат:** под кнопкой появляются два календаря и пресеты; надпись кнопки меняется на «▼  Свернуть».

2. **Задайте начало и конец периода.**
   - В поле **«С:»** выберите первую дату периода.
   - В поле **«По:»** выберите последнюю дату периода.
   - Формат дат: `DD.MM.YYYY`.

   **Ожидаемый результат:** оба календаря показывают выбранные даты; если «По:» раньше «С:», поля подсветятся предупреждением.

3. **(Необязательно) используйте пресет месяца.**
   - Кнопка **«Этот месяц»** — ставит С: = первое число текущего месяца, По: = сегодня.
   - Кнопка **«Пред. месяц»** — ставит диапазон прошлого месяца целиком.

   **Ожидаемый результат:** оба календаря заполняются датами выбранного месяца.

4. **Выберите куратора в блоке «🚀 СБОРКА»** (Общий / Борис / Иван), как в сценарии 1.

   **Ожидаемый результат:** выбран нужный куратор.

5. **Нажмите кнопку «📊 СОБРАТЬ ПЕРИОД».**
   Эквивалент — **Ctrl+M**. Программа соберёт все листы-даты внутри диапазона в один отчёт.

   **Ожидаемый результат:** прогресс-бар в StatsPanel, по окончании — тост об успехе и созданный файл.

> Если за период нужен ещё и РСЧ — нажмите **«🧾 СОБРАТЬ РСЧ ЗА ПЕРИОД»** (Ctrl+Shift+R) в этой же секции.

## 6. Сценарий 3: авто-сверка

**Авто-сверка** — это режим «всё за один клик». Программа сама последовательно выполнит:

1. сборку **Master-отчёта (Общий)**;
2. сборку **отчёта куратора Бориса**;
3. сборку **отчёта куратора Ивана**;
4. формирование **РСЧ**;
5. **сверку** Master ↔ РСЧ — итоговый отчёт расхождений с листами `Общий`, `Борис`, `Иван`.

### Когда использовать

- В конце рабочего дня, когда все файлы сотрудников готовы и нужно получить финальный пакет отчётов.
- Когда нужно быстро проверить, нет ли расхождений между Master и РСЧ.

### Как запустить

1. **Выберите дату** в блоке «📅 ВЫБОР ДАТЫ» (авто-сверка работает по одной выбранной дате).
2. Убедитесь, что **сеть доступна** (🟢).
3. В блоке «🚀 СБОРКА» нажмите кнопку **«✅ АВТОСВЕРКА»**.
4. Дождитесь завершения всех пяти шагов — прогресс виден в StatsPanel.

**Ожидаемый результат:** по очереди создаются три Master-отчёта и РСЧ, затем формируется файл сверки. В конце — тост об успехе со ссылкой открыть итоговый отчёт расхождений.

> **Важно:** авто-сверка не затрагивает уже готовые файлы ошибочно — она пересобирает их заново по выбранным файлам сотрудников. Сверка пишет отдельный файл и **не меняет** `Master_Report.xlsx`, отчёты кураторов или РСЧ.

## 7. Управление сотрудниками

Программа работает с 23 сотрудниками, чьи файлы лежат в сетевых папках. Сотрудников можно обнаруживать автоматически или добавлять вручную.

### Добавить сотрудника

1. В блоке «👤 СОТРУДНИКИ» нажмите **«➕ Добавить»**.
2. Введите имя сотрудника в появившемся диалоге.
3. Подтвердите.

**Ожидаемый результат:** сотрудник появляется в таблице вкладки «Сотрудники» со статусом «🔴 Нет файла» (пока не привязан файл).

### Привязать Excel-файл к сотруднику

1. Выделите сотрудника в таблице вкладки «Сотрудники».
2. Нажмите **«📎 Привязать»** в левой панели.
3. В диалоге выбора файла укажите `.xlsx` сотрудника.

**Ожидаемый результат:** в колонке «Файл отчета» появляется путь к файлу, статус меняется на «🟢 Готово» (если файл читается и содержит нужную дату) или «🟠 Нет даты» (если листа с выбранной датой нет).

### Drag-and-drop файла

Можно перетащить Excel-файл мышкой прямо на строку сотрудника в таблице (если функция доступна на вашей системе). Файл привяжется к сотруднику автоматически.

**Ожидаемый результат:** после отпускания файла путь сохраняется, статус обновляется.

### Удалить сотрудника

1. Выделите одного или **нескольких** сотрудников (Ctrl+клик для множественного выбора).
2. Нажмите клавишу Delete или используйте кнопку удаления в таблице.
3. Подтвердите в диалоге (для нескольких покажется список имён).

**Ожидаемый результат:** выбранные сотрудники исчезают из таблицы.

### Поиск и фильтр

Вверху вкладки «Сотрудники»:

- **Поле поиска** — фильтрует строки по имени или пути файла.
- **Выпадающий фильтр статусов** — варианты: «Все», «Готово», «Нет файла», «Должники».

### Найти должников

Кнопка **«📋 Должники»** копирует в буфер обмена список сотрудников, у которых нет файла или нужной даты. Вставьте (Ctrl+V) в любое сообщение или письмо.

**Ожидаемый результат:** в буфере обмена — список фамилий сотрудников, чьи отчёты не готовы.

### Бейджи статуса

| Бейдж | Статус | Что значит |
|---|---|---|
| 🟢 | Готово | Файл найден, лист с датой есть, строки распознаны |
| 🟠 | Нет даты | Файл есть, но листа с выбранной датой нет |
| 🔴 | Нет файла | Файл не найден по привязанному пути |

Строки таблицы дополнительно подкрашиваются: зелёным, янтарным или красным оттенком.

## 8. Темы и масштаб интерфейса

### Переключить тему

В блоке «🎨 ТЕМА» левой панели три переключателя:

- **☀️ Светлая** — бумажный светлый фон, navy-акценты.
- **🌙 Тёмная** — тёмный navy-charcoal, Linear-стиль.
- **💻 Системная** — следует за настройкой Windows (проверяется каждые 5 секунд).

Выбор сохраняется между запусками.

**Ожидаемый результат:** интерфейс немедленно меняет палитру; при следующем запуске сохранится выбранная тема.

### Изменить размер интерфейса (масштаб и плотность)

1. Нажмите **«⚙ НАСТРОЙКИ»** в левой панели.
2. Откройте вкладку **«🎨 Внешний вид»**.
3. Настройте:
   - **Масштаб** — режим «Авто» (по размеру экрана) или «Ручной».
   - **Размер** (user_scale) — множитель от 0.80 до 1.50; меняет все шрифты и контролы.
   - **Плотность** — «compact» (плотнее, ×0.70), «normal» (стандарт), «comfortable» (просторнее, ×1.35).
4. Нажмите **«Применить»** — изменения видны сразу (live-предпросмотр). Если не понравилось — **«Отмена»** вернёт исходные настройки.

**Ожидаемый результат:** интерфейс становится крупнее/мельче или плотнее/просторнее. Настройки сохраняются в `APP/config.yaml` и применяются при следующем запуске.

> Подсказка: на маленьком мониторе уменьшайте масштаб до 0.85–0.90 и ставьте «compact»; на большом 4K — увеличивайте до 1.20–1.30 и «comfortable».

## 9. Горячие клавиши

Девять сочетаний работают в любом месте главного окна. Нажмите **F1** или кнопку «⌨ ГОРЯЧИЕ КЛАВИШИ», чтобы открыть справочник.

| Сочетание | Действие |
|---|---|
| **Ctrl+D** | Собрать отчёт за день |
| **Ctrl+Shift+D** | Собрать по всем датам сразу |
| **Ctrl+M** | Собрать за период |
| **Ctrl+R** | Сформировать РСЧ за день |
| **Ctrl+Shift+R** | Сформировать РСЧ за период |
| **Ctrl+E** | Сверка данных (Master ↔ РСЧ) |
| **F5** | Обновить статус файлов сотрудников |
| **F1** | Показать справку по горячим клавишам |
| **Escape** | Отменить текущую операцию |

> **Отмена (Esc)** прерывает идущую сборку/РСЧ/сверку безопасно — частичные результаты не повредят已有的 файлы.

### 2. Панель

Список всех собранных файлов-отчётов (Master, кураторов, РСЧ, сверки) с датой и путём. Клик по строке — открыть файл или папку.

- **зелёный** — успех;

## 11. Тосты и сообщения об ошибках

### Что такое тост

**Тост** — небольшое всплывающее уведомление в углу окна. Появляется после операций и показывает результат. Цвет несёт смысл:

| Цвет | Тип | Когда |
|---|---|---|
| зелёный | успех | операция завершена, файл создан |
| красный | ошибка | что-то пошло не так |
| янтарный | предупреждение | часть данных пропущена, но отчёт собран |
| синий | информация | подсказка, не требующая действия |

### Ссылка «Подробнее ▼»

Если у тоста есть техническая деталь, под сообщением появляется ссылка **«Подробнее ▼»**. Кликните её — раскроется блок с уточнением (например, какой именно файл не читается или на какой строке сбой).

> «Подробнее» обычно нужно, чтобы понять причину ошибки. Основной текст тоста написан понятным языком («Не удалось прочитать файл сотрудника»), а в подробностях — путь и характер проблемы.

### Что делать при ошибке

1. Прочитайте основной текст тоста.
2. Раскройте «Подробнее ▼», если есть.
3. Откройте вкладку **«Логи»** — последние 150 строк подскажут, на каком шаге сбой.
4. Если проблема повторяется — см. [FAQ](#12-faq-и-устранение-неполадок) ниже.

> Программа устроена так, чтобы одна ошибка не роняла всю работу: если один файл сотрудника не читается, остальные всё равно собираются, а сбойный отмечается «🔴» в таблице и в истории.

## 12. FAQ и устранение неполадок

### Вопрос 1. Программа не запускается

**Симптом:** двойной клик по `ЗАПУСК.bat` — окно появляется и сразу исчезает, либо пишет ошибку.

**Что делать:**

1. Запустите `ЗАПУСК.bat` ещё раз и не закрывайте окно — прочитайте, на каком шаге сбой.
2. Откройте файл **`startup_log.txt`** рядом с `ЗАПУСК.bat` — там подробный лог запуска.
3. Откройте файл **`gui_error_log.txt`** — если сбой произошёл на шаге `Step 4.5/5. GUI import preflight`, причина описана здесь.
4. Убедитесь, что установлен **Python 3.12+** и при установке была отмечена галочка **«Add Python to PATH»**. Проверить: в командной строке наберите `python --version`.
5. Если пишет «Python not found» — установите Python с [python.org](https://www.python.org/downloads/) и перезапустите компьютер.

> Программа сама создаёт локальное окружение `.venv` и ставит библиотеки. Ручная установка `pip install` обычно не требуется.

### Вопрос 2. Кнопка серая и не нажимается

**Симптом:** кнопка «⚡ СОБРАТЬ ДЕНЬ» (или другая) не реагирует.

**Что делать:**

1. Идёт ли уже другая операция? Посмотрите на StatsPanel внизу левой панели — если прогресс-бар активен, дождитесь завершения или нажмите **Esc** для отмены.
2. Выбрана ли дата в «📅 ВЫБОР ДАТЫ»? Для сборки за день дата обязательна.
3. Для периода — заданы ли обе даты «С:» и «По:» и не перепутан ли порядок?
4. Перезапустите программу, если кнопка остаётся недоступной без видимой причины.

### Вопрос 3. Файл сотрудника не найден

**Симптом:** у сотрудника статус «🔴 Нет файла», хотя файл точно существует.

**Что делать:**

1. Проверьте путь в колонке «Файл отчета» — возможно, файл переместили или переименовали.
2. Нажмите «📎 Привязать» и заново укажите правильный путь.
3. Если файл на сетевом диске — убедитесь, что диск подключен (см. [вопрос 5](#вопрос-5-сеть-недоступна--)).
4. Проверьте, что файл не открыт в Excel в этот момент — открытый файл может блокировать чтение.

### Вопрос 4. Лист с нужной датой не находится (🟠 Нет даты)

**Симптом:** файл есть, но статус «🟠 Нет даты».

**Что делать:**

1. Откройте файл сотрудника в Excel и проверьте имя листа — оно должно быть в формате `DD.MM.YYYY` (например, `09.07.2026`).
2. Листы без года (например, `13.04`) **не считаются** валидной датой — переименуйте лист, добавив год.
3. Убедитесь, что выбранная в программе дата точно совпадает с именем листа.

### Вопрос 5. Сеть недоступна (🔴)

**Симптом:** индикатор сети красный: «🔴 Сеть: 0/3 дисков доступны».

**Что делать:**

1. Проверьте, что сетевые диски (`Q:` и т.п.) видны в «Этот компьютер» Windows. Если нет — переподключите их или обратитесь к системному администратору.
2. Жёлтый индикатор «🟡 Сеть: нет дисков» означает, что в `APP/config.yaml` не настроены пути к сетевым папкам — откройте «⚙ НАСТРОЙКИ» → вкладку «🌐 Сеть».
3. Нажмите **F5** — обновить статус после того, как сеть вернулась.

### Вопрос 6. Консолидация зависла

**Симптом:** прогресс-бар стоит на месте долго, ничего не происходит.

**Что делать:**

1. Нажмите **Esc** — безопасно отменить операцию. Частичные файлы не повредятся.
2. Проверьте вкладку «Логи» — возможно, программа ждёт ответа от сетевого диска (SMB-диски бывают медленными).
3. Слишком большой период (например, целый год из множества дат) может идти долго — попробуйте разбить на части или собрать за день.
4. Если зависание повторяется — перезапустите программу и соберите за один день, чтобы локализовать проблему.

### Вопрос 7. Как поменять тему

В блоке «🎨 ТЕМА» левой панели выберите **☀️ Светлая**, **🌙 Тёмная** или **💻 Системная**. Тема применится сразу и сохранится между запусками.

### Вопрос 8. Где мои отчёты

Все собранные файлы видны во вкладке **«Отчеты»** — с датой и путём. По умолчанию:

- Master-отчёт: `Master_Report.xlsx` в корне программы (или путь из настроек);
- отчёты кураторов — рядом;
- РСЧ-отчёт — в папке `РСЧ/`;
- отчёт сверки — туда, куда вы указали при сохранении.

Клик по строке во вкладке «Отчеты» открывает файл или его папку.

### Вопрос 9. Как обновить приложение

Запустите файл **`ОБНОВИТЬ_И_ЗАПУСТИТЬ.bat`** рядом с `ЗАПУСК.bat`. Скрипт:

1. Скачивает свежую версию программы с GitHub.
2. **Сохраняет ваши локальные данные** — `APP/config.yaml`, `APP/employees.yaml`, `APP/cache.db`, ваши Excel-файлы, `REPORTS/`, `РСЧ/`.
3. Обновляет только код программы и библиотеки.
4. Запускает обычный `ЗАПУСК.bat`.

> Если обновление не удалось — смотрите `update_log.txt`. Ваши данные при этом не теряются.

### Вопрос 10. Что делает РСЧ

**РСЧ** (расчётно-кассовое обслуживание) — контрольный отчёт по банковским счетам. Он строится из отдельных книг РСЧ и показывает расшифровку счетов. Используется как «контрольная точка» для сверки с Master-отчётом.

Режимы РСЧ:

- **за день** — кнопка «🧾 СОБРАТЬ РСЧ» (Ctrl+R);
- **за период** — кнопка «🧾 СОБРАТЬ РСЧ ЗА ПЕРИОД» (Ctrl+Shift+R) в секции «📆 ЗА ПЕРИОД»;
- **общий файл** — режим по умолчанию (отдельные-файлы убран как слишком медленный).

### Вопрос 11. Что такое алиасы сверки

Вкладка **«🔗 Алиасы сверки»** — таблица соответствий между названиями заказчика в Master-отчёте и в РСЧ. Если один и тот же контрагент в разных файлах записан по-разному, сверка не сможет их сопоставить автоматически. Алиас говорит программе: «эти два названия — один и тот же заказчик».

Добавьте соответствие через интерфейс вкладки, и при следующей сверке строки с матчем сойдутся корректно.

### Вопрос 12. Как изменить папку Master (путь к файлу)

1. Нажмите **«⚙ НАСТРОЙКИ»**.
2. Откройте вкладку **«📁 Пути и файлы»**.
3. Измените путь к мастер-файлу и корни отчётов сотрудников.
4. Нажмите **«Применить»**.

Настройки сохраняются в `APP/config.yaml`.

### Вопрос 13. Пропали данные / ошибка базы данных

**Симптом:** при запуске ошибка базы данных, история или сотрудники «сбросились».

**Что делать:**

1. Программа хранит данные в `APP/cache.db` (SQLite, режим WAL). Не удаляйте этот файл вручную.
2. Возле него есть файлы `cache.db-wal` и `cache.db-shm` — это нормальная часть WAL-режима, не трогайте их.
3. Программа делает **авто-бэкапы** (до 10 копий) — проверьте папку `backups/` рядом с программой.
4. Во вкладке «⚙ НАСТРОЙКИ» → «💾 Бэкапы» можно посмотреть список резервных копий и восстановить нужную.
5. Если ошибка не уходит — скопируйте всю папку программы (особенно `APP/`, `backups/`, `config.yaml`) и обратитесь к администратору.

### Вопрос 14. Как узнать, какие именно сотрудники не готовы

Откройте вкладку **«Сотрудники»**, в фильтре статусов выберите **«Должники»** — таблица покажет только тех, у кого нет файла или нужной даты. Нажмите **«📋 Должники»** — список скопируется в буфер обмена.

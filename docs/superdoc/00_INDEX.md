## Краткая сводка продукта (для заказчика)

**Master-Report Consolidator v5.6** — десктопное Windows-приложение (Python 3.12 / Tkinter) для финансовой консолидации Excel-отчётов сотрудников в единый Master-отчёт, РСЧ-отчёт и отчёт расхождений (сверку).

**Что умеет (42 фичи, F-001…F-042):**
- 📊 **Консолидация** — сбор сводного Master-отчёта из файлов сотрудников за день / период / все даты (3 режима, 3 куратора: Общий / Борис / Иван).
- 🧾 **РСЧ** — расчётно-кассовый отчёт по банковским счетам (4 режима: день / период одним файлом / период по файлам / по источникам).
- ✅ **Сверка** — отчёт расхождений между Master и РСЧ + авто-сверка (3 Master + РСЧ + сверка за 1 клик).
- 👤 **Управление сотрудниками** — авто-обнаружение 23 сотрудников в сетевых папках, ручное добавление/привязка, drag-and-drop.
- 🎨 **Премиальный UI** — тёмная/светлая темы (Linear-style), адаптивный масштаб (DPI), 3 режима плотности, tabular-figures для сумм, status-бейджи, welcome-onboarding.
- ⌨ **Горячие клавиши** — 9 сочетаний (Ctrl+D/M/R/E, F1/F5, Esc).
- 🛡 **Надёжность** — WAL-режим SQLite, integrity-check при старте, atomic-save, авто-бэкапы (×10), fail-soft парсинг, отмена операций.

**Доказательство качества:**
- **456 автотестов**, 0 регрессий (держится на протяжении 4 SHEAF-проходов редизайна).
- **WCAG AA** контрасты: body-on-card 15.8:1 (light) / 14.5:1 (dark).
- **18/18 code-gates** в `workspace/verify_gate.py` (exit 0).
- 90 бизнес-правил, 23 инварианта, 10 state-machines — формализованы в `docs/business/`.

## Глоссарий (термины домена)

| Термин | Что значит |
|---|---|
| **Консолидация** | Сбор сводного Master-отчёта из множества Excel-файлов сотрудников за дату/период |
| **Master-отчёт** | Итоговый сводный `.xlsx` (один лист «СВОД»): Источник/Заказчик/Исполнитель/Приход/Расход/Комиссия/Итог/% посредника/посредник 1/посредник 2/Фильтры |
| **РСЧ** | Расчётно-кассовое обслуживание — контрольный отчёт по банковским счетам (расшифровка счетов). Строится из отдельных книг РСЧ |
| **Сверка (reconciliation)** | Отчёт расхождений между Master-отчётами кураторов и РСЧ. Матчит строки по (исполнитель + заказчик + сумма) |
| **Куратор** | Группа сотрудников: Общий отчёт / Куратор Борис / Куратор Иван. У каждого свой набор колонок и стратегия расчёта посредников |
| **Алиас** | Ручное соответствие «заказчик-куратор ↔ заказчик-РСЧ» для матчинга при различающихся названиях (таблица `customer_aliases`) |
| **Сессия** | Один прогон операции (консолидация/РСЧ/сверка) с уникальным `session_id`, метаданными и статусом в БД |
| **Staging** | Сырые распарсенные строки до агрегации (таблица `staging_data`) |
| **Дата-лист** | Лист в исходном `.xlsx` сотрудника с именем-датой `DD.MM.YYYY` |
| **Маркеры заголовков** | Словарь `sh1.markers` в `config.yaml`: русские заголовки колонок → логические поля (customer/contractor/amount/…) |
| **Discovery** | Сканирование сетевых папок для авто-обнаружения файлов сотрудников (с кэшем для скорости на SMB-дисках) |
| **Приход / Расход** | Направление финансового потока строки (определяется по фильтрам + `income_overrides`/`return_keywords`) |

# Техническая документация: Master-Report v5.5

## 1. Обзор системы
Master-Report — это высокопроизводительное настольное приложение на языке Python, предназначенное для автоматизированного сбора, очистки и консолидации финансовых отчетов сотрудников из разрозненных файлов Excel в единый сводный отчет.

## 2. Архитектура модулей
Программа построена по модульному принципу:

*   **`main.py`**: Точка входа. Управляет жизненным циклом приложения и инициализацией GUI.
*   **`gui_master.py`**: Слой интерфейса (Tkinter). Реализует многопоточное обновление статусов, управление списком сотрудников и визуализацию процесса сборки.
*   **`consolidator.py`**: Ядро бизнес-логики. Отвечает за:
    *   Сканирование файловой системы.
    *   Интеллектуальное распознавание шаблонов Excel.
    *   Трансформацию данных с использованием высокоточных вычислений.
*   **`writer.py`**: Слой вывода. Обеспечивает запись данных в Excel с применением стилей, автоподбором ширины столбцов и атомарным сохранением.
*   **`audit_logic.py`**: Система логирования операций, фиксирующая каждое успешное или ошибочное чтение данных в `DEEP_AUDIT_REPORT.txt`.

## 3. Ключевые алгоритмы и оптимизации

### 3.1. Кэширование метаданных (`_sheet_cache`)
Для обеспечения мгновенного отклика UI при работе с сетевыми дисками (`Q:\`) внедрена система кэширования. Программа запоминает список листов файла и привязывает его к дате последнего изменения (`mtime`). Если файл не менялся, список листов берется из оперативной памяти.

### 3.2. Многопоточная сборка
Использование `ThreadPoolExecutor` позволяет параллельно обрабатывать файлы разных сотрудников. Это сокращает время генерации глобального отчета в 4-7 раз.

### 3.3. Умный поиск шапки
Вместо полной загрузки листа в Pandas, система сначала сканирует первые 150 строк через `openpyxl` в режиме `read_only`. Это позволяет найти строку с заголовками, не расходуя память на весь файл.

### 3.4. Атомарное сохранение
Для предотвращения порчи данных при сбоях, итоговый отчет сначала сохраняется как `.tmp`, и только после успешной записи заменяет основной файл через `os.replace`.

## 4. Стек технологий
*   **Язык**: Python 3.12+
*   **Обработка данных**: Pandas, Decimal
*   **Работа с Excel**: openpyxl
*   **Конфигурация**: ruamel.yaml (с сохранением комментариев)
*   **Интерфейс**: Tkinter + ttk + tkcalendar

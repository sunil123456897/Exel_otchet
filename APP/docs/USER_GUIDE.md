# Инструкция пользователя: Master-Report v5.5

## 1. Запуск программы
Для начала работы дважды кликните по файлу **`ЗАПУСК.bat`** в корневой папке проекта. Программа автоматически проверит наличие Python и необходимых библиотек, после чего откроет графический интерфейс.

## 2. Основные элементы управления
*   **Календарь**: Выберите дату, за которую вы хотите собрать отчет. Статусы в таблице обновятся автоматически.
*   **Таблица сотрудников**: Показывает текущую готовность отчетов.
    *   **🟢 ГОТОВО**: Данные найдены хотя бы в одном привязанном файле.
    *   **🟠 НЕТ ДАТЫ**: Файлы привязаны, но в них нет листа с выбранной датой.
    *   **🔴 НЕТ ФАЙЛА**: К сотруднику не привязан ни один файл.
*   **⚡ СОБРАТЬ ДЕНЬ**: Генерация отчета только за выбранную в календаре дату.
*   **🌍 СОБРАТЬ ВСЕ ДАТЫ**: Полное сканирование всех файлов и создание в итоговом отчете листов за все найденные дни.

## 3. Управление файлами и сотрудниками
### 3.1. Добавление сотрудника
Нажмите кнопку **«Добавить»**, введите имя и нажмите OK. Сотрудник появится в списке.

### 3.2. Привязка файлов
1. Нажмите **«Привязать»**.
2. Выберите сотрудника из списка.
3. Установите галочку **«Добавить к существующим»**, если вы хотите докинуть новые файлы к уже привязанным. Если галочку снять — старый список будет удален.
4. Выберите один или несколько файлов Excel в проводнике.

### 3.3. Удаление
Для удаления сотрудника нажмите на него **правой кнопкой мыши** в таблице и выберите «Удалить сотрудника».

## 4. Результат работы
Итоговый файл **`Master_Report.xlsx`** создается в корневой папке. 
*   Шапка в нем закреплена (всегда видна при прокрутке).
*   Ширина столбцов подбирается автоматически.
*   В колонке «Сотрудник» указано имя исходного файла для каждой строки.

## 5. Решение проблем
Если программа работает медленно или не видит файлы на диске `Q:\`:
1. Убедитесь, что диск `Q:` подключен и доступен в системе.
2. Проверьте файл `consolidation.log` — там пишутся подробности ошибок.
3. Используйте кнопку **«Обновить статус»** для принудительной перепроверки файлов.

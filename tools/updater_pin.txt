# is computed from the downloaded bytes and cannot detect a malicious push).

#   https://github.com/sunil123456897/Exel_otchet/compare/<old>...<new>

#   d9c8351a1b2c3d4e5f60718293a4b5c6d7e8f901
#
# Leave this file empty (only comments) to update from the branch HEAD with a
# warning and no commit verification (current default behaviour).
